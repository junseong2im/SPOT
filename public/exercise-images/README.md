# 운동 이미지 출처

이미지는 wger의 공개 exerciseinfo API가 제공하는 개별 이미지 라이선스 메타데이터를 확인해 가져왔습니다. AI 생성 표시는 제외했습니다. 각 파일의 원본 URL, 작성자, 라이선스 URL은 `ATTRIBUTION.json`에 보존되어 있습니다.

이미지는 변경하지 않았습니다. 각 이미지의 CC-BY-SA 3.0 또는 CC-BY-SA 4.0 조건은 해당 이미지에 적용되며, 앱 코드의 라이선스와 별개입니다. 앱의 운동 상세 화면에서도 작성자·라이선스·원본 링크를 제공합니다.

자료 출처: https://wger.de/api/v2/exerciseinfo/
라이선스 정보: https://wger.de/api/v2/license/

이미지는 참고 동작의 기구와 자세를 보여줍니다. 모든 운동 변형을 동일하게 표현하지는 않습니다. 정확한 이미지가 없는 Y-레이즈에는 다른 운동 사진을 대신 붙이지 않았습니다.
